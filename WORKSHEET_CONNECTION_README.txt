UOL DASHBOARD - YOUR ORIGINAL DESIGN WITH LIVE WORKSHEET LOADING

This package keeps the uploaded New-UOL-2026-main design and its chart code unchanged.

WINDOWS
1. Extract this ZIP fully.
2. Run START_CONNECTED_DASHBOARD.bat in the New-UOL-2026-main folder.
3. The local dashboard opens in your browser automatically.
4. Keep the data/*.xlsx files in their original locations.
5. Edit the original Excel workbook and save it, then refresh the browser to see updates.
   (Certain datasets may require the exact sheet names and column headings.)

NOTE: This is a local, read-only workbook connection via HTTP, not a cloud Excel/OneDrive
sync. Data imported as browser overrides (if supported by a page) can supersede bundled
workbook data until restored. The server disables cache to make worksheet edits visible.

The four original HTML pages remain present:
  index.html
  basic-reporting.html
  internship-placement.html
  mou-collaborations.html

No summary data was rewritten and no duplicate rows were automatically deleted.
