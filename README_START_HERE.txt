UOL TENTATIVE DASHBOARD — POWER BI-STYLE WEB VERSION

This is an HTML/CSS/JavaScript dashboard. No RStudio, Power BI or Windows launcher is included.

To publish the dashboard, upload the contents of the UOL Dashboard1 folder (including the data and assets folders) to GitHub Pages or another static web hosting service. Open the published index.html page in a browser.

Pages: Executive Overview, Basic Reporting, Internship / Placement, MoU Collaborations.
Internet connectivity is required for the externally loaded charting and Excel libraries.
Do not rely on opening index.html directly from disk: Excel files are fetched via HTTP(S).
Verify reported totals against the source workbook before official use.
