UOL Tentative Dashboard — Power BI-inspired web layout

Browser-based HTML/CSS/JavaScript; no RStudio, Power BI, .bat launcher or local server commands.

Publish this folder to GitHub Pages or another static web host (retain the assets/ and data/ folders), then open its index.html page.

Sections 1–3 each load their own Excel source. Section 2's organization chart normalizes organization labels, excludes placeholders, removes exact repeated records and shows Top 10, Top 15 or Top 20 organizations by selection. No full organization ranking table.

Internet access is needed for the external Chart.js and SheetJS scripts. Check figures before official reporting.
