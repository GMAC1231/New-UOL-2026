# UOL Power BI-Style Tentative Dashboard

This package is a **browser-based HTML/CSS/JavaScript dashboard**, not an RStudio project or native Power BI file.

## Publishing

Upload the `UOL Dashboard1` folder's contents, including `assets/` and `data/`, to **GitHub Pages** or another static web hosting service. Open the published `index.html` address in your web browser.

Do not open `index.html` directly as a `file://` URL; browsers may block the Excel `fetch()` requests. An internet connection is required for charting and Excel libraries loaded from CDNs.

## Included pages

- Executive overview
- Section 1: Basic reporting
- Section 2: Internship / Placement
- Section 3: MoU collaborations

Check all figures against the workbook before official university reporting.
